# E-Bike Speed Controller System

This project focuses on developing a motor speed controller for an electric vehicle prototype using Arduino.

## Overview
The system uses PWM control techniques to regulate motor speed and improve efficiency.

## Features
- PWM-based motor speed control
- Real-time monitoring using OLED display
- Stable and efficient performance

## Components Used
- Arduino
- BTS7960 motor driver
- Hall effect sensor
- OLED display
